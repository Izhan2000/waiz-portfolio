# Waiz Izhan — IT E-Portfolio

## Files
- index.html — website structure/content
- style.css — Dolphin Blue/Ocean theme, responsive layout and animations
- script.js — dark mode, typing effect, scroll reveal, active navigation, mobile menu and demo contact form

## How to run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Recommended: install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
5. The browser will open the portfolio.

## Important things to edit
Search in `index.html` for:
- `your.email@example.com`
- `LinkedIn — add your link`
- `GitHub — add your link`

Replace those with your real contact details.

You can also replace the project descriptions and add screenshots later.

## Notes
The contact form is currently a front-end demo. It does not send an actual email until it is connected to a backend or form service.
